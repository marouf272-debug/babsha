# Babsha

A Dhaka-themed property trading board game for the phone browser. Pass and play for 2 to 6 players, or play against the computer. English and Bangla. Works offline after the first visit and installs to the home screen.

Play: https://marouf272-debug.github.io/babsha/

A personal project shared with friends. Built with TypeScript, Vite and Three.js; all art and sound are made in code.

## Develop

```bash
npm ci
npm run dev
```

`npm test`, `npm run test:e2e` and `npm run lint` run the checks. CLAUDE.md lists every command. docs/PLAN.md is the plan, docs/RULES.md the rules, docs/DECISIONS.md the decision log, and docs/RELEASE.md explains releases and rollback.
