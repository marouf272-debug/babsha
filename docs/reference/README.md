# Style references (received 2026-11-08, before S5)

Seven phone screenshots from the owner, all from one existing commercial board game app (an Indian edition of "Business"). They are reference material only: not shipped with the game, not copied. The game takes principles from them, not that app's look, layout, graphics, Indian theme or its advertising (plan 1.2: no ads; plan 3.7: keep the India look out).

| File | Shows |
|---|---|
| ref-01-board.webp | Full board in portrait, action bar, four player cards around the dice |
| ref-02-pause-menu.webp | Pause dialog: music and sound toggles, help, leave game |
| ref-03-build-help.webp | Build dialog: tap a highlighted tile on the board |
| ref-04-sell-help.webp | Sell dialog, same pattern |
| ref-05-mortgage-help.webp | Mortgage dialog, same pattern |
| ref-06-redeem-help.webp | Redeem dialog, same pattern |

## What to take (owner's choice, D-71)

1. **Big readable tiles**: the board uses as much of the phone width as the camera allows, large tile names and prices, a color strip per set.
2. **Bold buttons and dialogs**: chunky rounded buttons in strong colors, dialogs with a colored header band, bold lettering.
3. **Player cards by the dice**: players in a 2 by 2 grid of cards (token, name, cash) with the dice in the middle.
4. **Tap tiles on the board**: Build, Sell, Mortgage and Redeem highlight the usable tiles and the player taps the tile.

## What not to take

- The flat top-down board view: the owner kept the tilted 3D Dhaka city from the plan (D-70).
- Indian city names, rupee sign, and the app's specific art, icons and color scheme.
- The advertising banner.
